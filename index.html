From product link to shortlist

Compare OKEYHAUL finds

Start with one item type and a detail that matters, such as low-top sneakers with a wide toe box or a zip hoodie with a two-way zipper. Record the item name, selected color, seller listing, current availability and date checked. If two rows show the same catalog photo, open both listings and compare the variant names and seller details.

Check OKEYHAUL product links

Reopen the original product URL before saving it. On a Weidian, Taobao or 1688 listing, check the chosen size, color code and minimum order quantity, where shown. Save the exact variant in your notes so you can recover it if the link later opens on a different option.

Review OKEYHAUL QC photos and sizing

Compare the shoe insole length with a pair that fits. For T-shirts and jackets, compare flat chest width, shoulder width and sleeve length with a garment measured the same way. For caps and bracelets, check head circumference or inner wrist circumference against the relevant size chart. If inspection photos are available, ask for a clear close-up of the size label and any area you need to inspect.

Estimate OKEYHAUL shipping costs

Use the destination country and postal code when requesting an international shipping quote. Compare the item subtotal, domestic shipping, any service fees and the international shipping charge in one currency. Record packed weight and box dimensions separately, and check whether import charges appear in the quote or are payable on delivery.

Frequently asked questions

What is an OKEYHAUL spreadsheet?

It is a list or directory used to organize product finds, source links and notes such as size, photos or weight. Check the current listing for the option you want.

Where do the category links go?

The category links open HipobuyFind. This is an independent guide with no official affiliation with OKEYHAUL or the brands pictured.

Can QC photos prove authenticity?

QC photos can show visible details such as stitching, color and labels. For authenticity, use a seller with verifiable provenance or seek independent authentication.

How do I estimate shipping before ordering?

Ask for the packed parcel weight and dimensions, then request a quote for your country and postal code. Check whether the carrier bills by actual or volumetric weight.
